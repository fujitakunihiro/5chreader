# 5ch Reader

5ちゃんねる公式BBSメニューから板一覧を読み込み、板のスレッド一覧と各スレッドのレスを表示する、ローカル用の閲覧専用リーダーです。まとめ記事や架空のレスは掲載しません。

## 起動

```sh
docker compose up --build -d
```

ブラウザで <http://localhost:8081> を開きます。板を選ぶとスレッド一覧を取得します。スレッドを開くとレスを50件ずつ表示し、前後のレスへ移動できます。各板・スレッドから5chの元ページも開けます。

```sh
docker compose down
```

板一覧は5ch公式の <https://menu.5ch.io/bbsmenu.json> から取得します。閲覧にはインターネット接続が必要です。
